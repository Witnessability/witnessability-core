# Naming and Marks Policy — Draft

## Category word

`witnessability` is intended to function as an open conceptual category. This policy does not claim exclusive control of ordinary descriptive use.

## Product and protocol names

`WitSeal`, `WEXP`, logos, and specific project branding require separate marks assessment. Registration and ownership status are currently `not_assessed` unless separately recorded.

## Descriptive implementation claims currently allowed

- Implements WEXP version X.
- Provides a CC-1–CC-18 Conceptual Consistency Mapping.
- Evaluated under Profile X.
- Signature verified / manifest verified / externally reproduced by identified party.

## Restricted or deferred claims

Do not use without a defined conformance/certification architecture:

- Witnessability Verified
- Certified Witnessability
- Officially Verified
- Verified by WitSeal

`Verified` must state: by whom, which claim, which profile, which Witness Case, result, and limitations.
