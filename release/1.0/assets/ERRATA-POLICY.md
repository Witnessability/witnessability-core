# Errata Policy

1. Released bytes are never silently replaced.
2. Each erratum has a stable identifier, affected artifact/hash/location, classification, proposed interpretation or correction, status, and date.
3. Errata clarify a released artifact but do not silently change signed normative meaning.
4. Normative changes require a new release version.
5. Individual errata are hash-bound; the append-only errata index is periodically signed.
6. Previous errata-index versions remain available.
7. GitHub assets are not reuploaded under the same release identity to conceal a change.
