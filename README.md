# Witnessability Conceptual Core 1.0

Witnessability is the claim-relative capability of a socio-technical arrangement to produce, preserve, and expose
an evaluable and challengeable evidence-and-argument graph connecting a Target Proposition to the represented
conditions and outputs of witnessing.
